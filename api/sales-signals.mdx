---
title: "Sales signals"
description: "Find current tenders, funding leads, news and company records."
---

Apiosk can combine several kinds of source data for a sales or research
question. Source availability, exact inputs and prices can change. Browse
the live directory before building a fixed integration.

## Find relevant sources

Search the source directory for terms such as <code>tenders</code>,
<code>funding</code>, <code>news</code> and
<code>company registry</code>:

~~~bash
curl -G https://gateway.apiosk.com/v2/sources \
  -H "Authorization: Bearer $APIOSK_KEY" \
  --data-urlencode "search=tenders"
~~~

Inspect <code>available_in_v2</code>,
<code>executable_capabilities</code> and <code>readiness</code>.
Then call <code>GET /v2/sources/{source_id}</code> for the operations,
input schemas and current prices that the runtime accepts. A registered
endpoint or advertised capability alone is not an execution promise.

Pulse Network is one source group with multiple services. Search for
<code>Pulse Network</code> to see matching services; inspect its source
detail to see the currently runnable operations and each operation's
underlying <code>source_id</code>.

## Let Ask combine sources

For a question involving several signal types, request a free plan first:

~~~bash
curl https://gateway.apiosk.com/v2/ask \
  -H "Authorization: Bearer $APIOSK_KEY" \
  -H "Content-Type: application/json" \
  -d '{"question":"Find recent tenders and company news for Dutch cybersecurity companies","execution_mode":"plan","limit":10}'
~~~

The response may ask for a country, company, period or other detail, or it
may return a priced plan. Answer a clarification before buying. Review the
plan's exact source steps and total ceiling; then run that saved plan with
<code>POST /v2/asks/{id}/run</code> if it answers the intended question.

## Read the evidence

Every returned document has its source, retrieval time and result reference.
Its <code>metadata</code> can include a source URL, links present in the
source record, subject identifiers, operation and actual charge. Missing
records or partial coverage should be reported as such; they are not evidence
that no tender, funding event or news item exists elsewhere.
