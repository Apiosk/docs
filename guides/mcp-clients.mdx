---

The hosted MCP URL is:

~~~
https://mcp.apiosk.com/mcp
~~~

## ChatGPT

Add the URL as a remote MCP connector. Complete the Apiosk sign-in and
connection consent when ChatGPT prompts you. If the client cached an older
tool list, refresh the connector or start a new chat.

## Claude Code

~~~bash
claude mcp add --transport http apiosk https://mcp.apiosk.com/mcp
~~~

Then complete the account sign-in when the client opens it. The hosted
server exposes the four buyer tools described in [MCP server](/mcp/overview).

## Another MCP client

Configure a Streamable HTTP server with URL
<code>https://mcp.apiosk.com/mcp</code> and let the client complete OAuth.
Create an Apiosk account at [app.apiosk.com/signup](https://app.apiosk.com/signup)
if you do not have one.

Browsing and planning do not charge your balance. For a paid request,
review and approve the plan's total ceiling in the interactive card. The
Gateway then runs it and saves the result. If a question lacks context,
answer the clarification rather than approving a different request.

For a backend that needs an organisation-owned credential, follow the
[API quickstart](/overview/quickstart) instead.
