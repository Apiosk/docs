title: "Quickstart"
description: "From nothing to a paid call in four steps."
---

You need an Apiosk organisation with a funded balance. Everything below takes
one terminal.

## 1. Create a key

In the app, open **Organisation → API keys → Create API key**. Give it a name,
an expiry, a per-request limit, a monthly limit and the permissions it needs.

Copy the secret when it is shown — it is shown once.

```bash
export APIOSK_KEY="apk_org_live_…"
```

## 2. Check it works

```bash
curl https://gateway.apiosk.com/v2/balance \
  -H "Authorization: Bearer $APIOSK_KEY"
```

You get the organisation's balance and this key's limits. If that answers
`401`, the key is wrong, expired or revoked; `403` means it lacks
`billing:read`.

## 3. Find a source

```bash
curl -G https://gateway.apiosk.com/v2/sources \
  -H "Authorization: Bearer $APIOSK_KEY" \
  --data-urlencode "search=company registry"
```

Then read one source to get its operation ids, input fields and prices:

```bash
curl https://gateway.apiosk.com/v2/sources/kvk \
  -H "Authorization: Bearer $APIOSK_KEY"
```

Browsing is free.

## 4. Buy one call

```bash
curl https://gateway.apiosk.com/v1/execute/kvk/company_registry.search \
  -H "Authorization: Bearer $APIOSK_KEY" \
  -H "Idempotency-Key: quickstart-1" \
  -H "Content-Type: application/json" \
  -d '{"company.name":"Mollie B.V."}'
```

```json
{
  "id": "6f0b…",
  "status": "completed",
  "data": { "companies": [{ "kvkNummer": "30204462", "naam": "Mollie B.V." }] },
  "usage": { "cost": { "amount": 0.023, "amount_micro_usd": "23000", "currency": "USD" } },
  "balance": { "remaining": { "amount": 47.797, "amount_micro_usd": "47797000", "currency": "USD" } }
}
```

That is a purchase: one source, one price, one charge.

## When you do not know the source

Let Apiosk plan across sources, see the price, then run it:

```bash
curl https://gateway.apiosk.com/v2/ask \
  -H "Authorization: Bearer $APIOSK_KEY" \
  -H "Content-Type: application/json" \
  -d '{"question":"Registered address and latest filed accounts for Mollie B.V."}'
```

The answer holds a plan with a per-step price and a total ceiling. Run it with
`POST /v2/asks/{id}/run`, or ask with `"execution_mode":"auto"` and a
`max_spend` to have it run straight away when it fits.
