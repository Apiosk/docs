## 1. Create a team account

[Sign up in the app](https://app.apiosk.com/signup), choose a team account,
and confirm your email. This creates an organisation. An owner or admin can
open **Organisation → API keys**. Fund the organisation's main balance before
making a paid call; creating a key and browsing sources do not charge it.

## 2. Create an API key

Give the key a name, expiry, per-request limit, monthly limit and the
permissions it needs. Copy the secret when it appears; it is shown once.
Keep it on your server.

~~~bash
export APIOSK_KEY="apk_org_live_…"
~~~

For this guide, enable <code>sources:read</code>,
<code>sources:execute</code> and <code>billing:read</code>. Add
<code>ask:create</code> and <code>ask:execute</code> to run questions
through Ask.

## 3. Check the key and browse

~~~bash
curl https://gateway.apiosk.com/v2/balance \
  -H "Authorization: Bearer $APIOSK_KEY"

curl -G https://gateway.apiosk.com/v2/sources \
  -H "Authorization: Bearer $APIOSK_KEY" \
  --data-urlencode "search=company registry"
~~~

The directory includes sources that cannot currently run. Choose a row with
<code>available_in_v2: true</code>, then inspect its executable operations,
exact inputs and current prices:

~~~bash
curl https://gateway.apiosk.com/v2/sources/kvk-dutch-business-register \
  -H "Authorization: Bearer $APIOSK_KEY"
~~~

## 4. Run one operation

Use an operation and input returned by the source detail. Set a unique
<code>Idempotency-Key</code> for this purchase:

~~~bash
curl https://gateway.apiosk.com/v1/execute/kvk-dutch-business-register/company_registry.search \
  -H "Authorization: Bearer $APIOSK_KEY" \
  -H "Idempotency-Key: quickstart-1" \
  -H "Content-Type: application/json" \
  -d '{"company.name":"Mollie B.V."}'
~~~

A completed response includes <code>data</code>,
<code>results[].metadata</code>, <code>usage.cost</code>,
<code>usage.held</code> and <code>balance.remaining</code>. If it
returns HTTP 202, read the saved run at <code>GET /v2/runs/{id}</code>.
This is a paid operation; do not run the example simply to test a key.

## When you do not know the source

Ask for a free priced plan:

~~~bash
curl https://gateway.apiosk.com/v2/ask \
  -H "Authorization: Bearer $APIOSK_KEY" \
  -H "Content-Type: application/json" \
  -d '{"question":"Registered address and filed accounts for Mollie B.V."}'
~~~

If the response needs input or an entity selection, ask the person for the
missing detail and submit a clarified question. If a plan is ready, review
its total ceiling before calling <code>POST /v2/asks/{id}/run</code>.
See [Ask](/api/ask) and [Prices and balance](/overview/payment-model).
