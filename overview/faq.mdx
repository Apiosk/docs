## Can our team create its own account and API key?

Yes. Sign up at [app.apiosk.com/signup](https://app.apiosk.com/signup), choose
a team account, and confirm your email. The owner or an admin can then open
**Organisation → API keys** to create a key with permissions and spending
limits. Keep the secret on your server; it is displayed once.

## Do API calls need a key?

The buyer API in these docs uses an organisation key sent as
<code>Authorization: Bearer apk_org_live_…</code>. Browse sources with
<code>GET /v2/sources</code>, inspect executable operations with
<code>GET /v2/sources/{source_id}</code>, and use [Ask](/api/ask) when the
source is not known. The hosted [MCP server](/mcp/overview) uses a person's
account connection instead of an organisation API key.

## Does seeing a source mean every endpoint is ready to buy?

No. The directory includes entries that are still discovery-only or
restricted. Check <code>available_in_v2</code>, <code>readiness</code>, and
<code>executable_capabilities</code>; then read one source for the currently
executable operations, exact inputs, and prices. Do not infer availability
from a source name or its raw endpoint count.

## When does a question cost money?

Browsing and planning are free. A purchase starts only after the plan is
authorized within its displayed total ceiling. The result includes actual
charges, any amount still held, and source references. See
[Prices and balance](/overview/payment-model).

## What if the question needs more context?

An Ask response can return <code>needs_input</code> with a clarifying
<code>message</code>, or <code>needs_selection</code> with candidates. Ask
the person for the missing fact or the right entity. In the app or MCP card,
continue the saved task using its offered action. In the buyer HTTP API,
submit a new clarified question; it has no input-continuation endpoint.

## What if a run takes longer than the request timeout?

HTTP 202 includes the run id. Read <code>GET /v2/runs/{id}</code> to resume
from the saved state. Retry a paid request with the same
<code>Idempotency-Key</code>.

## Can an API key spend a workspace budget?

No. Organisation keys spend the main balance. People and assistant
connections can spend a workspace budget when operating in that workspace.
