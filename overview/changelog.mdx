## 2026-09-30

- The [Ask API](/api/ask) returns selectable API contracts; selected execution
  preserves the chosen API and inputs under one total spending cap.
- Saved structured annual accounts now show readable key figures and aligned
  financial tables in the App, with the original response available as JSON.
  Reopening results does not buy the data again.
- **View full answer** opens the complete saved result. Mobile result drawers
  support pulling down to dismiss, with a fixed header and download footer.

## 2026-09-23

- Buyer docs now follow the self-service path from team signup to an
  organisation API key, source discovery, a priced plan and a saved result.
- Source discovery distinguishes listed sources from executable operations.
  Use <code>available_in_v2</code>, <code>readiness</code>,
  <code>executable_capabilities</code> and the per-source operation detail.
- The hosted MCP guide describes its four assistant-visible tools and the
  separate approval action in the interactive card.

## 2026-09-22

- Organisation owners and admins can create keys with permissions, expiry,
  a per-request limit and a monthly limit. Keys spend the organisation's
  main balance. See [API keys](/app/api-keys).
- The buyer API exposes source browsing, direct execution, Ask plans, saved
  runs, balance and usage. See [Quickstart](/overview/quickstart).
