Apiosk buys data for you. You ask for something — a company's filed accounts, a
registered address, a tender — and Apiosk finds the sources that can answer,
shows the price before anything is bought, buys only what it needs, and hands
back the source's own document with what it cost.

One catalogue, one price list, one ledger. Three ways to reach it.

## The shortest paid call

```bash
curl https://gateway.apiosk.com/v1/execute/kvk/company_registry.search \
  -H "Authorization: Bearer $APIOSK_KEY" \
  -H "Idempotency-Key: my-request-1" \
  -H "Content-Type: application/json" \
  -d '{"company.name":"Mollie B.V."}'
```

The key says who pays, the path says what to run, the body carries the inputs.
The answer arrives with the data, what it cost and what is left.
[Start here](/overview/quickstart).

## What holds it together

- **One catalogue.** Every source in `GET /v2/sources` can be called directly
  and can appear in a plan. There are no API-only sources.
- **One price.** What a source costs in the catalogue is what a run is charged,
  fee included. The per-source usage of a run adds up to its total.
- **Money moves in one order.** Approve, reserve, run, settle. Nothing is paid
  before it is bought, and a failed call is refunded.
- **Retries are safe.** An `Idempotency-Key` makes a repeat call the same call.
