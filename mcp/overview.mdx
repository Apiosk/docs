---
title: "MCP server"
description: "Connect an assistant, review one price, and receive saved source results."
---

Use the hosted MCP endpoint in ChatGPT, Claude or another compatible client:

~~~
https://mcp.apiosk.com/mcp
~~~

It uses Streamable HTTP and account OAuth. [Create an account](https://app.apiosk.com/signup)
first if needed. When the client requests a protected action, complete
sign-in and approve the connection and its spending limits in the app.
Connection approval sets limits; it does not approve a future data purchase.

## Tools the assistant sees

| Tool | Purpose | Can buy data? |
| --- | --- | --- |
| <code>apiosk_sources</code> | Browse and filter the source directory | No |
| <code>apiosk_discover</code> | Plan a question, price it or ask for missing context | No |
| <code>apiosk_execute</code> | Continue a saved task using a returned action | Only after purchase approval |
| <code>apiosk_status</code> | Read saved status, results and charges | No |

The interactive card has a separate approval action that the person uses
to approve the displayed total price ceiling. The assistant must not
approve for the person. After approval the Gateway runs the task and saves
the results; the assistant should read that state instead of starting
another purchase.

## When information is missing

The card or assistant asks a clarifying question for
<code>needs_input</code>, or presents candidates for
<code>needs_selection</code>. Answer with the missing fact or choose
the intended entity. The saved task continues with the offered action;
there is no need to start a new purchase merely to clarify.

Browsing the directory does not promise that every published endpoint is
runnable. Check the returned availability and let
<code>apiosk_discover</code> verify whether the exact question has a
priced plan.

## Spending and recovery

A connection has a per-request and daily limit. The person can change or
revoke it in the app under **Integrations**. A workspace-bound connection
spends that workspace's budget; otherwise it uses the person's balance.
Use <code>apiosk_status</code> and the saved task reference for a
follow-up or interrupted response. Status reads do not buy data.

For setup commands, see [MCP clients](/guides/mcp-clients). Server
integrations without a person in the loop use an
[organisation API key](/api/authentication).
